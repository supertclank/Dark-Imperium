# PHB rules resolution

PHB v1.0 only. Printed page = PDF page − 13. See `review/rules-resolution.json` for full affected-ID sets. The affected sets conservatively include source-page neighbours for impact review, not a claim that every neighbouring entity has the defect.

Each entry distinguishes source resolution from an application capability. RESOLVED does not publish the package. §1.5 specific-feature precedence does not silently resolve equally specific v1.0 contradictions.

## PHB-RULE-001 — Hiveborn Origin eligibility

Group: PHB-001. Category: **CONFLICTING_RULES**. Status: **OPEN**.

Source: PDF 26, 27; printed pages subtract 13.

Problem/evidence: Matrix permits Kin; Allowed Species prose omits them. Voidborn also differs for Aeldari. Both passages are v1.0; §1.5 gives no clear precedence between these eligibility lists.

Possible interpretations:

1. Use matrix eligibility.
2. Use the per-Origin Allowed Species prose.
3. Obtain an explicit erratum; neither v1.0 passage establishes precedence.

Decision and automation impact: Retain both; unresolved Origin eligibility is an explicit fact gate, never unrestricted.

Affected content: di.background.craftworld_outcast, di.background.forge_world, di.background.hiveborn, di.background.militarum_regiment, di.background.mining_hold_guild, di.background.penal_worlder; full set in the machine-readable ledger.

Human decision: For Hiveborn, does the eligibility matrix or the Allowed Species list govern? State permitted species.
