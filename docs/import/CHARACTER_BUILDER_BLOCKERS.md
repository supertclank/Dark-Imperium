## Minimum publishable character dataset

All 6 species,10 resolved Origins,12 classes,45 subclasses with complete selected-level grants; source-supported creation order and choices; standard-array/attribute modifier/HP/AC/movement/proficiency policies; acquisition/equip/use prerequisites; all required starting weapons/armour/items with resolved references; source-defined starting power lists/tier counts/actions; creation-relevant feats and pools; validated source/engine capabilities and exactly one reviewed profile in a closed lock. Narrative niche benefits may remain reviewed ManualRule. At campaign start level3, apply level1–3 grants and all required choices; do not imply the default starting level is mandatory.

The full builder should not start against this draft lock. Independent generic UI and validation infrastructure may be prototyped with explicit examples, but must not present unresolved PHB creation as legal. Next task: obtain the exact remaining rules rulings, then finish core item/power/profile mappings and certify this minimum dataset.
