# Level 4 advancement release report

Human Veteran advancement from level 3 to 4 is implemented for the 24 certified Origin/doctrine families. Entry is an explicit, atomic v4-to-v5 profile upgrade. Existing character creation and older pinned profiles remain unchanged.

1. **PHB-RULE-014 approval:** current Constitution modifier applies retroactively to each class level, with a minimum of one HP per class level. Current HP does not increase when maximum HP rises and is clamped if maximum HP falls. Exact user approval text, timestamp, SHA-256 and provenance are recorded in the decision ledger and `approved-level4-rulings.txt`.
2. **PHB-RULE-015 approval:** the level-4 choice is +2 to one ability, +1 to two distinct abilities, or one Talent. ASI increases cannot exceed 20 or waste points. This cap is specific to ASI processing.
3. **PHB-RULE-016 approval:** Talent ownership is unique unless repeatability is explicitly approved. Universal Traits are separate. No repeatable Talent was inferred.
4. **Ruling totals:** 15 resolved and 21 unresolved out of the original 36. PHB-RULE-059 remains separately tracked. These approvals do not resolve other open rulings.
5. **Canonical choice:** `di.choice.veteran.level4_improvement` provides ASI_PLUS_TWO, ASI_SPLIT and TALENT branches. The pinned profile supplies choices, prerequisites, benefit text and subchoices; React does not calculate game values.
6. **Calculation policy:** final ability scores include existing base/species mechanics, then the selected ASI; modifiers and derived statistics follow. HP recalculates each class level using the current Constitution modifier, then separate feature effects. A Constitution 13-to-15 Veteran reaches maximum HP 36 at level 4, not 40. An injured character at 11 HP remains at 11 HP. Server previews write nothing.
7. **Talent audit:** all 50 Chapter 12 Talents were individually reviewed: 18 READY_WITH_MANUAL_RULES, 27 INELIGIBLE for this scope, two BLOCKED_BY_RULE, one BLOCKED_BY_ENGINE and two BLOCKED_BY_CONTENT. See [the complete inventory](LEVEL4_TALENT_READINESS.md).
8. **Published Talent pool:** Armour Familiarity, Bayonet Fighter, Brawler, Breacher, Close-Quarters Killer, Combat Medic, Crisis Runner, Cybernetic Implant, Field Armourer, Heavy Weapon Training, Hip Fire, Hive-Blooded, Iron Discipline, Point Blank Execution, Rapid Reload, Relic-Bearer, Tactical Reposition and Weapon Specialist. Manual effects are explicitly presented as manual.
9. **Subchoices:** Weapon Specialist requires one of nine canonical weapon groups and applies its baseline damage bonus to matching actions and rolls. Cybernetic Implant requires one of the ten approved PHB-RULE-051 minor augmetics. Augmetic effects remain manual, including Optical Implant alternatives; the sheet labels vision before manual augmetic effects. Conditional stacking under PHB-RULE-058 is not inferred.
10. **Certification scope:** 24 Human Veteran level-4 families extend the existing 64 family rows to 88. Creation remains on v4 through level 3. No non-Human level-4 or level-5 path is published.
11. **Immutable release:** `di-phb-1.0-tier1-v5`, adapter `phb-tier1-kotlin-v1`, digest `b061617c32eb325d73552b56b7e7c240faf77b5ac44de309375c929574dbf98b`. The exporter refuses differing existing release bytes. Older profile snapshots are preserved.
12. **Upgrade contract:** `human-veteran-v4-v5-1` requires the exact certified v4 source, Human Veteran level 3, a supported destination configuration and explicit user consent. Before upgrade, the current character is recalculated under v5 and checked for compatibility across abilities, HP, armour, movement, initiative, saves, skills, inventory, resources, features, subclass and actions.
13. **Persistence and transaction order:** request idempotency and character state are locked and checked; the contract, consent, compatibility and destination choice are validated; final scores, modifiers, HP, derived statistics, actions and rolls are calculated. Existing inventory/resources/current HP are preserved, new resources start full, and current HP is clamped when necessary. Choices, level, profile, runtime state, upgrade history and advancement result commit atomically. Forced failure rolls everything back. Retries return the original result; stale updates are rejected. Existing roll history retains its original profile digest.
14. **Content validation:** all 146 content tests pass, including approval provenance, immutable profile contract, ASI option legality, subchoice pools and the 50-Talent audit.
15. **Backend validation:** all 88 backend tests pass. Coverage includes all 24 families and every published choice, ASI boundaries, invalid/duplicate/ineligible Talent choices, HP policies, explicit upgrades, roll preservation, idempotency, stale state, incompatible resources and transactional rollback.
16. **Frontend validation:** all 69 frontend tests pass and TypeScript checking passes. Coverage includes branch changes, distinct split abilities, Talent/subchoice presentation, owned-Talent filtering and explicit upgrade consent.

Dexterity 15-to-17 changed modifier +2-to-+3, initiative +4-to-+5, AC 14-to-15, Lasgun attack +4-to-+5, damage 1d8+2-to-1d8+3 and grenade DC 12-to-13. Maximum HP rose from 25 to 32 without healing. 22. **Remaining restrictions:** Grenadier awaits engine mapping for range/DC; Suppressive Discipline depends on PHB-RULE-022; Dead Calm depends on 022/046. Imperial Flexibility lacks a certified selectable proficiency/tool domain; Last Order Standing lacks a certified executable temporary-HP grant and trigger/overlap handling. Other unresolved rulings, including 020 and conditional stacking 058, remain blocked where applicable. Manual Talent and augmetic effects are not represented as automated. Non-Human advancement beyond existing certification and the production build/Docker limitations remain open.
23. **Next milestone:** certify non-Human levels 2–4 and Ratling Sharpshooter before level 5 or Extra Attack. Do not infer new design rulings to extend that scope.
