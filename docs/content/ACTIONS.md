# Actions

The normative action contract remains [DOMAIN_SCHEMAS](DOMAIN_SCHEMAS.md#actions-reactions-psychic-powers), with costs/outcomes/trigger semantics in [RULES_EFFECTS](RULES_EFFECTS.md) and roll compilation in [DICE_ROLLING](DICE_ROLLING.md). This index fills the missing documentation link; it does not introduce an alternate action schema.

PHB draft additions and remaining capability proposals are tracked in [PHB_SPEC_EXTENSIONS](PHB_SPEC_EXTENSIONS.md). Source calculation policies are in [CALCULATION_POLICIES](CALCULATION_POLICIES.md). Unknown action targeting, costs, outcomes or context must remain unresolved/manual; a base damage template is not a complete attack action.
